# Roadster2 月球探索 v3.1 · SELENE 基地与工作原理影像馆

运行：在本目录双击 start.cmd（需要已安装 Python 3），然后用浏览器访问
http://127.0.0.1:18769/
也可在本目录执行：python -m http.server 18769 --bind 127.0.0.1
请通过 HTTP/HTTPS 访问，不能直接双击 index.html。运行无需联网、npm 安装或构建。
若端口已占用，可把 18769 改为其他端口。面向桌面键盘操作。

v3 基地路线（按 moonbase.png 的环形舱、透明穹顶和前置停车塔构建）
- 开始页选择“基地演练”，从底部入口前方开始，沿蓝色灯带按 W 驶入。
- 进入停车墙前方（x≤46）按 E，外部供能吸附轨道将车头转向上方，四轮贴墙。
- 松开 W/S 停在补气位，接口自动连接，高压气罐约 4.2 秒从空充满。
- 即使气罐耗尽也能停靠；墙面停车不消耗车载气体。W/S 可手动升降。
- 月面真空中不再自动回气；可收集气罐或返回基地。舱内车载压缩机慢充，墙面接口快充。
- 气量至少 25% 时点按空格，辅助沿墙上升、绕过顶部弯轨、倒姿从顶部气闸飞出。
- 出舱后短暂保持倒姿，再自动翻正；松开方向键即可降落月面，WASD 可接管姿态。
- E 可手动解除墙面吸附。基地内限速 12m/s，非入口方向有外壳碰撞阻挡。
- 舱内显示 101.3kPa / O₂ 21%，离开气闸显示真空；舱内关闭月尘和轮迹。
- 穹顶内生态绿植、环形步道、居住舱窗、太阳能板、天线、生命支持设备、储气罐和管线。
- 科幻保压场与轨道吸附为游戏设定；并非流体或电磁系统的工程模拟。
- 基地几何由代码生成并按材质合批，不携带参考 PNG，不计视频的 v3 ZIP 小于 10MB；含视频的 v3.1 部署 ZIP 上限为 50MB。

保留 v2 的提升与左右转向修正
- openracing 连续冷气喷流：带动态噪声/脉冲结构的气柱、扩散尾迹和喷口照明。
- 根据 GLB 实际喷口配置：01–04 底喷、05–08 尾喷；修正重复坐标变换及反向发射。
- 起跳和落地扬尘、姿态控制喷流、空气耗尽后的停止反馈。
- 120Hz 固定步长物理；月球重力 1.62m/s²；空中喷气沿车体方向作用。
- 单次计量喷气耗气、带阻尼的空中俯仰/横滚、松开输入自动回正。
- 完整单轴 360° 才计为空翻，计数同步到 HUD 和结算。
- 倒挂有约 0.95 秒吸附过渡；接触管顶后计程；耗气或驶出区域后脱离。
- 追尾/远景保持地平线正向，座舱视角跟随车体；相机避让地面和管内边界。
- 4K 月壤色彩 + 2K 法线 + 1K 粗糙度，双尺度采样减少重复，细分地形和实例化碎石。
- 车漆环境反射、跟随车辆的阴影、连续轮迹、管道实体顶板、结构肋和引导灯带。
- 精细/均衡/流畅三档；可关闭速度镜头（FOV、边缘速度模糊、轻微色差及震动）。

操作
W/S：前进/制动倒车；腾空时俯仰
A/D：转向；腾空时横滚
Shift：尾喷加速（地面、空中、倒挂均可，消耗空气）
空格：点按起跳，空中按住底部喷气（推力随车体姿态变化）
E：基地墙面吸附/解除；在熔岩管内切换倒挂（至少 15% 空气，启动消耗 5%）
Enter：停在基地墙面补气位时结算（先完成任意一项任务）
C：追尾 / 座舱 / 远景
F：尾翼形态
R：重置任务；M：静音；Esc：暂停

任务保持原有结构：8 颗氦-3、300km/h、4s 腾空或完整空翻、50m 倒挂，
完成任意一项后返回基地墙面停靠并按 Enter 结算；进入基地不会自动弹窗中断补气。
熔岩管位于 x≈460–660、z≈0；
从初始位置向东行驶约 400m 到达。指南针现在指向实际最近的未收集晶体。
倒挂、跳跃与空中自动回正为街机辅助机制，非完整刚体模拟。

开发
主入口：game.js；game2.js 仅保留兼容导入，不再维护两份实现。
src/config.js：参数；src/terrain.js：地形；src/vehicle.js：物理；
src/effects.js：喷流、粒子、轮迹、后处理；src/surface.js：月面与管道细节。
src/base-layout.js：共用基地尺寸与轨道；src/moonbase.js：程序化基地与镜头；
src/base-physics.js：吸附、补气、爬升、倒姿出舱和碰撞。
测试：在开发目录运行 npm test（无需 npm install）。
贴图复现：python tools/bake-regolith.py（需要 NumPy、Pillow）。
打包：python tools/package-demo.py。以 10,000,000 字节为严格上限，
导出仅包括实际运行资源、可读源码和许可文件，排除旧包、日志、测试面板与中间图。
ZIP 根目录包含 index.html，可直接上传静态托管。
新版输出 roadster2-moon-demo-v3.zip；旧版 v1 / v2 ZIP 保留在项目上级目录。

v3.2 基地体验修复
- 相机统一按可行驶地板避障，取消跟随距离变化造成的瞬移。
- 基地镜头平滑过渡，并限制切换时的平移、转向速度；出舱至落地保持稳定跟拍。
- 基地路线采用稳定外部视角，结束后平滑恢复选择的追尾/座舱/远景视角。
- 入口气闸增加中文标牌、发光门框、地面导向箭头与可见的蓝色隔离场。
- 出舱翻正与快速下降辅助，接近地面减速；WASD、空格或 Shift 可接管取消辅助。
- 标准路线出舱到落地约 6.6 秒（原约 17.3 秒）；普通月面跳跃物理不变。
